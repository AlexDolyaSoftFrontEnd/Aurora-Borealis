# React Developer Landing — Oleksandr Dolinskyi

Одностраничная интерактивная стартовая страница с эффектами параллакса, ауророй, свечением, «светлячками», а также анимированным выводом имени. Всё выполнено на чистом HTML, CSS и JavaScript без библиотек.

##  Основные особенности

### Визуальные эффекты

* Мягкий **radial-gradient фон** в тёмных ночных тонах
* **Aurora Borealis** (северное сияние) с плавной анимацией
* **3 слоя параллакса** с разной скоростью
* **Fog layers** (туман) с независимой анимацией
* **Луна**, реагирующая на движение курсора
* Генерация и анимация **40 светлячков** (fireflies)
* Лёгкая **blur-glass карточка** (glassmorphism UI)

### Логика и взаимодействие

* Реалистичный **mouse-parallax эффект**
* Плавный drift-эффект для тумана, света и фигур
* **Анимация набора имени** (typewriter-effect)
* Блокировка открытия DevTools, копирования и выделения
